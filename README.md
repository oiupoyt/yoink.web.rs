# yoink.web.rs

A native Rust fork of the terminal video downloader `yoinks` (https://github.com/pablostanley/yoinks).

> This is a Rust fork of [yoinks](https://github.com/pablostanley/yoinks).

yoink any video. paste. yoink. done.

Download videos from YouTube, X/Twitter, Instagram, Threads, TikTok and 1,800+ other sites — right from your terminal.

## Features
- **Rust-native implementation**: No Node.js runtime required.
- **TUI & CLI**: Interactive TUI parity with upstream + scriptable CLI mode.
- **Self-updating Engine**: Managed `yt-dlp` binary with automatic updates.
- **Playlist support**: Enumerate and select playlist entries.
- **Web Build**: Independently deployable, self-hosted web service.
- **Restyled Theme**: Minimalist, clean TUI theme.
